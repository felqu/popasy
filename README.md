# Forma — демонстрация оценки знаний команды

Интерфейс на Blazor Web App (.NET 8, Interactive Server), встроенный в существующий ASP.NET Core API.

## Запуск

Нужен SDK .NET 8 с ASP.NET Core Runtime.

```bash
dotnet restore APItests.sln
dotnet run --project APItests/APItests.csproj --launch-profile http
```

Открыть http://localhost:5296. Документация существующего API доступна по адресу http://localhost:5296/swagger.

## Возможности

- `/` — обзор, показатели и активность за выбранный период.
- `/tests` — библиотека с поиском, фильтрами и назначением тестов.
- `/generator` — генерация 3–8 демонстрационных вопросов, редактирование вопросов, вариантов, объяснений и сохранение теста.
- `/tests/{id}` — содержание и параметры теста, назначение сотрудникам.
- `/employees` — сотрудники, поиск, фильтр по отделу и добавление коллег.
- `/results` — назначения, результаты, фильтры и экспорт отфильтрованных данных в CSV с UTF-8 BOM.
- `/take/{id}` — демонстрационное прохождение, подсчёт баллов и разбор ответов.

## Ограничения демоверсии

Генератор **не обращается к внешнему ИИ**: выбирает готовые примеры для клиентского сервиса, информационной безопасности или командной работы по теме и контексту. Уровень и отдел — метаданные теста; сложность автоматически не адаптируется. Редактируйте примеры перед реальным использованием. Замена генератора на внешний сервис изолирована в `DemoQuestionGenerator`.

Общее демо-пространство хранится в памяти сервера и сбрасывается при перезапуске. Начальные результаты — примеры. У самостоятельно пройденных тестов сохраняются ответы для разбора. Ограничение времени информационное; крайний срок назначения проверяется при завершении. Повторные активные назначения одному сотруднику не создаются; просроченное назначение можно повторить.

Авторизация, роли, отправка писем и постоянное хранение не реализованы. Все посетители имеют доступ к одному пространству; используйте только тестовые данные. Для демоверсии SQL Server не нужен. Существующая регистрация EF Core сохранена, но её строку подключения в `appsettings.json` необходимо заменить перед использованием базы.
